# GO Mobility website

Cinematic responsive site built with React, Vinext and Sites.

## Develop
npm install
npm run dev

## Validate
npx tsc --noEmit
npm run build

## Content status
The imagery of the city and GO Smart Hub is original AI-generated concept photography. Vehicle assets are manufacturer reference images; vehicle availability, service rollout and future markets are not claimed as current deployments. The original R&D white paper and charging reference attachments were not supplied.

The contact form prepares a local text file. It does not send enquiries or register applicants. Connect an approved contact endpoint before a public commercial launch.

Motion uses CSS transforms, scroll-linked reveals, a guided journey and progressive route paths rather than a real 3D scene or rendered video. Reduced-motion preferences are respected. No browser interaction QA was run.
